# Compound Interest Tool

A fast, mobile-friendly compound interest calculator and investment growth calculator that estimates future value with optional monthly contributions. This savings calculator and interest rate calculator is a lightweight, single‑page financial planning tool for quick compounding interest and personal finance projections.

**Live compound interest calculator:** [Compound Interest Tool](https://compound.jamesonsaunders.com/)

**GitHub source code:** [Compound Interest Tool repository](https://github.com/jamesonsaunders/Compound-Interest-Tool)

## Features

- Compound interest calculator with adjustable compounding frequency
- Monthly contribution support for savings and investment growth
- Clean, app‑like UI optimized for mobile and desktop
- Instant updates as you type

## How It Works

This calculator uses the standard compound interest formula, plus optional monthly contributions:

- Base growth: $A = P(1 + r/n)^{nt}$
- Contributions: monthly deposits compounded monthly

Where:

- $P$ = principal (starting amount)
- $r$ = annual interest rate
- $n$ = compounding periods per year
- $t$ = years
